# UX/UI Design Specifications — Daily English

## 1. ปรัชญาการออกแบบ (Design Philosophy & Mood)

- **อารมณ์และความรู้สึก (Mood)**: Minimal, Warm, Mature, Editorial
- **เป้าหมาย**: สร้างความรู้สึกสงบ ผ่อนคลาย น่าอ่าน เหมือนกำลังเปิดอ่านนิตยสารหรือสมุดบันทึกคุณภาพดี หลีกเลี่ยงสีสะท้อนแสง สีจัดจ้าน และองค์ประกอบเกมที่กระพริบหรือสร้างความกดดัน
- **หลักการสื่อความหมาย**:
  - ไม่ใช้สีเพียงอย่างเดียวในการสื่อความหมาย (ต้องมี Icon และข้อความกำกับเสมอ)
  - ไม่ใช้อีโมจิแทนไอคอนหลัก แต่ใช้ Semantic Icons (เช่น Lucide SVG icons) ที่มีความคมชัด ประณีต และสม่ำเสมอ

## 2. Design Tokens (CSS Variables)

| Token Name | Hex Value | Role & Usage |
|---|---|---|
| `--color-bg` | `#F8F9F5` | สีพื้นหลังหลักของแอป (Warm Paper Tone สบายตา) |
| `--color-surface` | `#FFFFFF` | พื้นผิวการ์ด, Modals, Panel ด้านข้าง |
| `--color-primary` | `#245C4F` | สีหลัก (Deep Forest Green) ปุ่มสำคัญ, Active tabs |
| `--color-primary-soft` | `#E7F0EA` | สีเขียวอ่อนสำหรับไฮไลต์, พื้นหลัง badge, active state |
| `--color-accent-soft` | `#F7E8D7` | สีครีมอบอุ่น (Linen/Biscuit) สำหรับชี้แนะข้อมูลสำคัญ |
| `--color-text` | `#182A25` | สีตัวอักษรหลัก (Dark Evergreen-Charcoal คมชัดสูง) |
| `--color-text-muted` | `#596A63` | สีตัวอักษรรอง คำอธิบาย วันที่ และ metadata |
| `--color-border` | `#DCE4DE` | เส้นขอบการ์ด เส้นคั่น และกรอบ input |
| `--color-error` | `#B42318` | สีแจ้งเตือนข้อผิดพลาดและการลบข้อมูลสำคัญ |

### Spacing Scale
- `var(--space-xs)`: `4px`
- `var(--space-sm)`: `8px`
- `var(--space-md)`: `12px`
- `var(--space-base)`: `16px`
- `var(--space-lg)`: `24px`
- `var(--space-xl)`: `32px`
- `var(--space-2xl)`: `48px`

### Radii & Sizing
- `var(--radius-card)`: `20px` (ความโค้งมนของการ์ดและโมดัล)
- `var(--radius-control)`: `12px` (ความโค้งมนของปุ่ม, input, select)
- `var(--content-max-width)`: `1200px` (ความกว้างสูงสุดของหน้า Dashboard, Practice, Phrases)
- `var(--lesson-max-width)`: `760px` (ความกว้างโฟกัสสำหรับหน้าระหว่างเรียน)
- **Minimum Touch Target**: `44px` x `44px` ทุกปุ่มกดบนจอสัมผัส

### Typography
- **Primary Font**: `'Sarabun', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Body Text**: ขนาด `>= 16px` เพื่อให้อ่านสบายตา ไม่ต้องเพ่ง
- **Line Height ภาษาไทย**: `1.6` ถึง `1.7` ป้องกันสระและวรรณยุกต์ซ้อนทับกัน

### การตรวจสอบ Responsive Test Cases:
- **Mobile (375px)**: ตัวหนังสือไม่ล้นการ์ด ปุ่ม Primary ด้านล่างไม่ทับเนื้อหา รองรับ safe-area-inset-bottom
- **Tablet (768px)**: ปรับแถบเมนูให้กระชับ การ์ดแสดงผล 2 คอลัมน์อย่างเป็นระเบียบ
- **Desktop (1440px)**: Sidebar ซ้าย 232px เนื้อหาตรงกลางกว้างสูงสุด 1200px และจัดกึ่งกลางสวยงาม

## 4. Accessibility & Motion

- **Color Contrast**: อัตราส่วน Contrast ของข้อความหลักกับพื้นผิวผ่านเกณฑ์ WCAG AA (`#182A25` บน `#F8F9F5` และ `#FFFFFF` ได้อัตราส่วน > 10:1)
- **Keyboard Navigation**:
  - มี Visual Focus Ring ชัดเจน (Outline 2px สี `#245C4F` พร้อม offset 2px)
  - รองรับการกด `Tab`, `Shift+Tab`, `Enter`, `Space` และปุ่ม `Esc` สำหรับปิด Modal
  - เมื่อปิด Modal ต้องคืน Focus กลับไปยังปุ่มที่เป็น Trigger เสมอ
- **Reduced Motion**:
  - เมื่อเปิด `prefers-reduced-motion: reduce` ให้ปิด Transition และ Animation ทั้งหมด ให้เปลี่ยนสถานะแบบทันที

## 5. Screen Breakdown & Interactions

### 1. Onboarding (`/onboarding`)
- ขั้นตอนสั้น 4 สเต็ป:
  1. ชื่อที่อยากให้เรียก (Default: "ปุ๊ก")
  2. เป้าหมายการฝึก (ชีวิตประจำวัน / งานกราฟิกและการตลาด / เล่นเกม)
  3. ระยะเวลาที่สะดวก (5 นาที / 15 นาที)
  4. ความมั่นใจในปัจจุบัน (เริ่มต้น / พอเข้าใจ / อยากพูดคล่องขึ้น)
- มีปุ่ม "ข้าม (Skip)" ได้ตลอดเวลา
- เมื่อกดเสร็จสิ้น จะนำเข้าสู่หน้าบทเรียนแรกทันที

### 2. Today (`/`)
- ส่วนบน: วันที่ปัจจุบัน, คำทักทายอบอุ่น, สวิตช์สลับโหมด 5 นาที / 15 นาที
- **Hero Card**:
  - แสดงชื่อบทเรียนประจำวัน หมวดหมู่ และสิ่งที่จะทำได้หลังฝึก
  - ปุ่ม Action เด่น "เริ่มฝึกวันนี้" (หากมีบทเรียนค้างอยู่ ปุ่มจะเปลี่ยนเป็น "ฝึกต่อ")
- ส่วนรอง:
  - 4 ขั้นตอนของวันนี้ (ฟัง -> พูด -> ใช้ -> ทบทวน)
  - จำนวนวลีที่ครบกำหนดทบทวนในคลัง
  - ความคืบหน้า 7 วันล่าสุด (จุดแสดงความสม่ำเสมอจริง)

### 3. Practice (`/practice`)
- ตัวกรองหมวดหมู่: ทั้งหมด, Design & Marketing, Daily Life, Gaming
- ช่องค้นหาชื่อบทเรียน
- การ์ดบทเรียน: ชื่อภาษาไทย, ชื่อภาษาอังกฤษ, เวลาโดยประมาณ, Badge สถานะ (ยังไม่เริ่ม / กำลังฝึก / จบแล้ว)
- Empty State: แสดงเมื่อค้นหาไม่พบ พร้อมปุ่ม "ล้างการค้นหา"

### 4. Lesson Flow (`/lesson/:lessonId`)
- ส่วนบน: ปุ่มย้อนกลับ (มี Confirmation หากกำลังเรียนอยู่), ชื่อบทเรียน, Step Indicator (1. Listen -> 2. Repeat -> 3. Use it -> 4. Review -> 5. Summary)
- ส่วนล่าง: Primary Action Bar ลอยตัวติดด้านล่าง รองรับคีย์บอร์ด
- **Listen Step**:
  - เล่นเสียงผ่านปุ่มกดเท่านั้น (ไม่เล่นอัตโนมัติ)
  - เลือกประโยคเพื่อฟังซ้ำได้อิสระ
  - ปุ่มปรับความเร็ว 0.75x หรือ 1.0x
  - ปุ่ม Toggle ซ่อน/แสดง Transcript ภาษาอังกฤษ และคำแปลภาษาไทย
  - Graceful Fallback: หากเบราว์เซอร์ไม่มีเสียงภาษาอังกฤษ แสดงข้อความแจ้งเตือนและให้กดไปต่อได้
- **Repeat Step**:
  - แสดงประโยคทีละประโยค
  - ปุ่มอัดเสียง (ขอ Microphone permission ในคลิกแรก)
  - เมื่ออัดเสร็จ: ปุ่มหยุด, ปุ่มฟังเสียงตัวเอง, ปุ่มลองใหม่
  - Typed Fallback: หากปฏิเสธไมค์หรือไมค์ไม่พร้อม มีช่องพิมพ์ตอบให้ฝึกพิมพ์แทน
  - ไม่มีการให้คะแนนหรือแปลงเสียงเป็นตัวหนังสือหลอกลวง
- **Use it Step**:
  - คำถามปลายเปิดให้ผู้ใช้ตอบเกี่ยวกับชีวิตหรืองานของตนเอง
  - ช่องพิมพ์คำตอบภาษาอังกฤษ
  - ปุ่ม "ดูแนวทางคำตอบ (Example)": แสดงตัวอย่างพร้อมป้าย "ตัวอย่าง" เด่นชัด และมี Checklist ตรวจสอบตนเอง (Self-check)
- **Review Step**:
  - แฟลชการ์ดแสดงภาษาไทย ให้ผู้ใช้นึกก่อน
  - ปุ่ม "เปิดดูเฉลย" -> พลิกการ์ดแสดงภาษาอังกฤษและตัวอย่างประโยค
  - ปุ่มผลลัพธ์: "ยังจำไม่ได้" (นัด 10 นาที) หรือ "จำได้" (เลื่อนขั้น Spaced Repetition)
- **Summary Step**:
  - สรุปเวลาที่ฝึกจริง (Active Duration ไม่รวมเวลาที่ซ่อนแท็บ)
  - แสดงจำนวนประโยคและวลีที่บันทึกเข้าคลัง
  - ปุ่ม "กลับหน้าหลัก"

### 5. My Phrases (`/phrases`)
- ช่องค้นหาคำศัพท์ / กรองตามหมวด / กรองเฉพาะวลีที่ถึงกำหนดทบทวน (Due)
- การ์ดวลี: วลีอังกฤษ, คำแปลไทย, ประโยคตัวอย่าง, ปุ่มฟังเสียง, Stage ปัจจุบัน
- ปุ่ม "เพิ่มวลีใหม่" (เปิด Modal บันทึก)
- เมนูจัดการ: แก้ไข และลบ (การลบมี Toast แจ้งเตือนพร้อมปุ่ม Undo ภายใน 5 วินาที หรือ Confirm Modal)

### 6. Progress (`/progress`)
- ข้อมูลตามจริง 100%:
  - จำนวนเซสชันที่เรียนจบทั้งหมด
  - เวลารวมที่ฝึกจริง (นาทีและชั่วโมง)
  - วันที่ฝึกในช่วง 7 วันที่ผ่านมา
  - จำนวนวลีที่รอการทบทวน
  - ประวัติการเรียนย้อนหลัง (วันเวลา, ชื่อบทเรียน, โหมดเวลา)
- Empty State ชัดเจนหากเพิ่งเริ่มใช้งาน

### 7. Settings (`/settings`)
- ข้อมูลผู้ใช้: เปลี่ยนชื่อ, เป้าหมาย, ระยะเวลาที่ต้องการ (5 หรือ 15 นาที)
- Timezone: ค่าตั้งต้น Asia/Bangkok
- Backup & Restore:
  - ปุ่ม "Export ข้อมูล JSON" (ดาวน์โหลดไฟล์สำรอง)
  - ปุ่ม "Import ข้อมูล JSON" (ตรวจสอบ Schema ก่อนเสมอ พร้อมยืนยันก่อนทับข้อมูล)
- Danger Zone:
  - ปุ่ม "Reset ข้อมูลทั้งหมด" พร้อม Modal พิมพ์ยืนยัน ป้องกันอุบัติเหตุ
- คำอธิบาย: ระบุชัดเจนว่าข้อมูลทั้งหมดบันทึกอยู่บนเครื่องนี้ ไม่มีการซิงค์ข้ามเครื่อง
